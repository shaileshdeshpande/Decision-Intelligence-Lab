# Decision Intelligence Lab

Advancing financial decision-making through AI-enabled research, structured analysis, and continuous learning.

## Purpose

This repository is the authoritative library for the Decision Intelligence Lab (DIL). It brings together professional materials, original research, research platforms, public writing, club work, and website assets in one version-controlled system.

## Repository map

- `01_Professional/Resume/` - master and role-specific resumes
- `02_Position_Papers/` - numbered position papers and release notes
- `03_Research_Platforms/` - living research systems, including AICAS and SICAS
- `04_LinkedIn/` - posts, articles, connection messages, and outreach templates
- `05_Club_Materials/` - presentations, case competitions, and speaking notes
- `06_Research/` - company, market, industry, and reading notes
- `07_Website/` - website copy and assets
- `08_Release_Notes/` - repository-wide release notes

## Current starter documents

- Resume v1.0 - editable baseline resume with clearly marked fields
- PP-001 v1.0 - initial position-paper framework on AI-enabled investment research

## Versioning

Documents use semantic versions: `v1.0` for an initial release, `v1.1` for a meaningful revision, and `v2.0` for a substantial repositioning or redesign. Update `CHANGELOG.md` whenever a document is released or materially changed.

## Working practice

1. Start from the latest version rather than rewriting from scratch.
2. Preserve earlier releases.
3. Remove all bracketed placeholders before external use.
4. Record material changes in the relevant release notes and in `CHANGELOG.md`.
